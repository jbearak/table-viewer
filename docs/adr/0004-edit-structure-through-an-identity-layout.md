# Edit worksheet structure through an identity layout and shift coordinates only at save

Edit mode inserts, deletes, and moves rows and columns by recording a Worksheet Layout: the prospective order of a worksheet's body rows and columns, by identity, with removed rows and columns kept in place as tombstones for the rest of the session. Source cells keep their source coordinates as keys for the whole session, so cell edits, highlights, conflicts, and base validation are unchanged, and physical coordinates change in exactly one place, the save planner. Formula references are anchored to identities and rendered from the current layout rather than rewritten after each gesture, which keeps each structural action confined to one worksheet's Pending Changes; the cost is that a few gestures Excel resolves one at a time (a range corner moved past the other, a deleted corner whose gap is refilled, a range cornered on a discarded appended row) render from the final state instead, and Review Changes flags every formula that might be affected.

This supersedes ADR 0003's "without introducing arbitrary row deletion" and the append-rows design's "do not add a second symbolic formula representation". ADR 0003's rule for undoing saved appends is unchanged, and Pending Appended Rows stay outside the layout, in their own band, so appending still never shifts an existing row or reference.
