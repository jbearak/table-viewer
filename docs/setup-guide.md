# Table Viewer setup and 10-minute try-out

Table Viewer is available in two forms. Both open Excel, CSV, and TSV files, remember your viewing choices, and automatically refresh when a file changes on disk. Choose the one that best fits how you work:

- [**Standalone desktop app**](setup-guide-desktop-app.md) — the simplest choice if you want Table Viewer to behave like a regular spreadsheet app. It does not require VS Code. The app is available for Apple Silicon Macs running macOS 12 or later and for x64 or Arm-based PCs running Windows 10 or 11.
- [**VS Code extension**](setup-guide-vscode-extension.md) — the best choice if you already work in VS Code, use Linux, open files on a remote system with VS Code, or want a synchronized CSV/TSV preview beside the source text.

Each guide takes about 10 minutes and uses the same two small sample workbooks. You will try the main viewing tools, then replace a workbook while it is open to see Table Viewer preserve your compatible layout, sort, filter, and annotation choices.

The two forms share the same viewer, but keep their saved views separately. A layout you create in the desktop app does not currently appear in the VS Code extension, or vice versa.
