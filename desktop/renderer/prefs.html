Table Viewer Preferences

Changes save as you make them.

Appearance

Font used throughout the app. Leave empty for the default.
Text size used throughout the app.
System follows the OS light/dark setting.
Themes for the mode the app is in right now. Light and dark remember separate themes, so switching color schemes brings back the theme you picked for that mode.
Default placement of worksheet tabs. Can be overridden per file.

Editing

With Diff on, every cell you edit keeps showing its original value next to the new one. You can still toggle Diff from the toolbar for the current viewer session.

Files

Rows beyond this are truncated with a banner.
Larger files (xlsx, xls, csv, tsv) are refused instead of opened.

Updates

Checks once when you open Table Viewer. Downloads and restarts always require your approval. If you skip a version, it stays skipped until a newer version is released.
